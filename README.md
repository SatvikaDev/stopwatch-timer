# Stopwatch Timer

A simple and clean Stopwatch Timer built using **HTML, CSS, and JavaScript**.

🔗 **Live Demo:** https://satvikadev.github.io/stopwatch-timer/

### Features

* Start the timer
* Pause the timer
* Reset the timer
* Simple and clean UI

### Tech Used

* HTML
* CSS
* JavaScript

### How to Run

1. Clone the repository
2. Open `index.html`
3. Start using the stopwatch
